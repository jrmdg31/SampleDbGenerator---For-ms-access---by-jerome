Windows blocked the file? Quick fix

Seeing “These files can’t be opened — Your Internet security settings prevented one or more files from being opened”? That’s Windows being cautious about downloaded files. Nothing is wrong with the file. Pick a fix:

  1. Open File Explorer and go to your Downloads folder.
  2. Right-click SampleDB_builder.vbs and choose Properties.
  3. At the bottom of the General tab, tick Unblock, then click Apply and OK.
  4. Double-click the file again. Your database appears in the same folder.
