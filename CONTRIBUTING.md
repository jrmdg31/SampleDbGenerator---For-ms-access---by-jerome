# Contributing

Thanks for wanting to help. Seriously, it means a lot. ☕

## Quick start

1. Fork the repo and clone it.
2. Create a branch: `git checkout -b my-change`
3. Edit `index.html`. Everything (HTML, CSS, JS) lives in that one file on purpose, so it stays easy to host and easy to read.
4. Open `index.html` in a browser and test your change.
5. Commit, push, and open a pull request.

## Ground rules

- **Keep it dependency-free.** No frameworks, no CDN scripts, no build tools. This needs to work offline on old school computers.
- **Keep it old-browser friendly.** Avoid brand-new JavaScript features when a simple alternative exists.
- **Test both formats.** If you touch the script generator, try `.mdb` and `.accdb` if you can.
- **Respect reduced motion.** New animations should switch off under `prefers-reduced-motion`.
- **Keep the look consistent.** Dark background, amber accent, small uppercase labels, numbered sections.
- **Small pull requests beat giant ones.** One idea per PR is easier for me to review.

## Reporting bugs

Use the **Bug report** issue form. The more detail you give (Windows version, Access version, exact error), the faster I can fix it.

## Ideas welcome

New field types, better sample data, more languages, clearer instructions, accessibility improvements. Open an issue and let's talk.
